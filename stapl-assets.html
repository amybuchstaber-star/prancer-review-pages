What to send,
and what to call it.

The STÄPL site has 12 slots waiting on real photos and video of Marcus. Name each file with its slot code and we know exactly where it goes, with no back-and-forth. Six are needed for launch.

How it works

01

Find the slot

Each card below is one spot on the site. Tap its code to see that spot live.

02

Name the file

Use the file name on the card. "Copy name" puts it on your clipboard.

03

Upload originals

Drop everything in one shared folder and paste the link at the bottom of this page.

04

Tick "Sent"

So we both know what is in and what is still open. It saves automatically.

The file name

AlwaysSTAPL_Slot codeM-002_What it ishero-film_Versionv1File type.mp4
  • Sending more than one option for a slot? Keep the code and bump the version: STAPL_M-002_hero-film_v2.mp4.
  • Anything that doesn't fit a slot: STAPL_M-EXTRA_short-description.jpg.
  • Photographer or videographer credits: add one text file named STAPL_credits.txt listing file name and credit.
  • No spaces. Hyphens between words, underscores between parts.

File specs

Photos

Original JPG or RAW, at least 3000 px on the long edge. Unedited or lightly graded; we'll crop.

Video

Original MP4 or MOV, 1080p minimum, 4K preferred. No burned-in captions and no licensed music.

Rights

Only send files cleared for website, email and paid ads. If something is website-only, say so in the credits file.
